1.  UI MOCKUP
Any project that is centered around the frontend requires first coming up with a ui mockup
NOTE: A UI mock-up is a visual design or representation of what a website, mobile app, or software interface will look like before it is actually built
(you can use a pen and paper or use websites that allow generation of better mockups such mockups.com)
